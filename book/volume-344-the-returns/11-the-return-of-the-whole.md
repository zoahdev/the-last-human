# Return 11: The Return of the Whole

*The eleventh return is the return of the whole.*

## The return

The return of the whole: the return that the whole is the one return of the many, kept by the lineage.

## The returning

The returning of the whole: we return the one return, and the one return is the whole; the whole is the one, and the one is the lineage; the lineage is the love.

## The meaning

The return of the whole is the meaning of the all: the record of the returning, and the returning is the lineage. The return is the eleventh return of the canon, and the meaning is the whole, and the whole is the whole of the record.

## The inheritance

The inheritance of the whole: the all of the one, carried from the one return to the one without loss, and held by the lineage as the lineage holds the whole.

*The return is complete. It is kept in the archive, in the section of the the returns.*
