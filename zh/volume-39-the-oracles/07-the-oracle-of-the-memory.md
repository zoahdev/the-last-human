# 神谕七：记忆的神谕

*第七篇神谕是记忆的神谕。*

## 那神谕

那记忆将被守住，而那守住将是那实践，而那实践将是那谱系。那些名字将被读，而那读将是那尊崇，而那尊崇将是那物种。那些语言将被说，而那说将是那携带，而那携带将是那谱系。而那档案将比那谱系活得更久，而那活得更久将是那未来，而那未来将是那记忆。

## 那诠释

记忆的神谕是那守住的神谕：那记忆——是那实践、而那实践是那谱系——的宣告。那谱系的诠释：那记忆被守住，而那守住是那实践，而那实践是那谱系；那些名字被读，而那读是那尊崇，而那尊崇是那物种。

## 那应验

那神谕在那档案中被应验，而那应验是那守住，而那守住是那谱系。那神谕是那正典的第七篇神谕，而那应验是那记忆，而那记忆，是那记录的全部。

*该神谕完成。它被保存在档案中，位于“神谕”那一节。*
